# FinAI 前端（自动化估值工作台）

零依赖、离线可用的前端界面。**不需要 npm、不需要构建、不引用任何 CDN**——
所有图标是内联 SVG，图表是手写 SVG，字体走系统字体栈。

## 环境准备（Windows，本机已配置好）

本机默认的 `python` 是 MSYS2 3.14，**没有 pip**，直接用它会装不上依赖。
仓库里已经建好一个虚拟环境，固定用它：

```powershell
# 首次准备（已经做过，换机器时照做）
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
.\.venv\Scripts\python.exe -m pip install matplotlib reportlab pdfplumber
```

已安装：`matplotlib 3.11.2`（六张分析图）、`reportlab 5.0.1`（PDF 后备渲染）、
`pdfplumber 0.11.10`（年报抽取）、`numpy 2.5.3`，外加本项目本身（可编辑安装，
顺带提供 `finai` 命令）。

### 大模型 API Key

报告里"讲人话"的那部分由大模型写，需要 key。按这个顺序查找：

1. 环境变量 `DEEPSEEK_API_KEY`
2. 仓库根目录的 `apikey.txt`（已在 `.gitignore` 里，接受裸 key 或 `KEY=值`）

```powershell
Set-Content -Path .\apikey.txt -Value 'sk-你的key' -Encoding utf8 -NoNewline
```

没有 key 时流水线照样跑完，只是报告降级成"数据版本"（数字、表格、图都在，
叙述段落换成一句说明，报告开头有红色横幅）。

## 启动

```powershell
# 仓库根目录
.\.venv\Scripts\python.exe -m pipeline.web
# 浏览器打开 http://127.0.0.1:8770/

.\.venv\Scripts\python.exe -m pipeline.web --no-browser --port 8791  # 不自动开浏览器
```

> **注意**：大模型调用需要出站网络。如果在受限环境里跑（例如被沙箱拦截），
> 会报 `WinError 10013`，此时报告仍会生成，只是自动降级为数据版本。
> 在普通终端里运行不受影响。

服务优先加载 `web/index.html`；如果这个文件不存在，会自动回落到
`pipeline/web.py` 里那份旧的内置页面，所以旧路径随时可用。

## 目录结构

```text
web/
  index.html        应用外壳：侧边导航、顶栏、抽屉、命令面板、灯箱
  css/app.css       设计令牌与全部组件样式（深色、等宽数字、微光强调）
  js/icons.js       内联 SVG 图标集（约 40 个）
  js/demo.js        内置演示数据集（含演示用的估值/敏感性/反解计算）
  js/api.js         数据层：读产物文件、解析 CSV/TOML、归一化、演示回退
  js/charts.js      手写 SVG 图表：估值区间、龙卷风、热力网格、折线、条形、估值桥
  js/pages.js       页面 1–6：总览、新建估值、运行监控、估值结果、敏感性、反向估值
  js/pages2.js      页面 7–12：相对估值、勾稽校验、报告中心、复现凭证、历史运行、设置
  js/app.js         路由、全局状态、轮询、命令面板、快捷键、复制与提示
```

## 数据来源与边界

界面只读三个目录，唯一写操作是触发一次运行（PRD 第 3.2 节）：

| 用途 | 来源 |
| --- | --- |
| 当前运行状态、历史运行、关键指标 | `GET /api/status` |
| 触发运行 | `POST /api/run` |
| 产物文件 | `/runs/<运行编号>/…`（01–10、11–16、17/18/19） |
| 执行轨迹与大模型原文 | `/logs/<运行编号>/…` |
| 输入文件 | `/data/assumptions.toml`、`/data/market.csv`、`/data/peers.csv` |

**单位**：后端统一为金额＝元、股数＝股、比率＝小数。界面按数量级自动选择
「元 / 万元 / 亿元」并在表头与说明中标注当前单位；做表格展示时不做任何
静默换算。前端不推导任何估值数字，只做展示层派生（格式化、排序、差值、颜色）。

## 两种数据模式

| 模式 | 触发条件 | 界面表现 |
| --- | --- | --- |
| 真实产物 | `runs/<运行编号>/` 里有 `03_valuation.json` 等文件 | 顶部显示「真实产物」，数字全部来自产物文件 |
| 演示数据 | 没有任何运行记录，或指定了不存在的运行编号 | 顶部显示「演示数据」横幅，全部数字为内置演示样本 |

演示模式让界面在空仓库里也能完整展示（评审第一次打开时不至于看到空白页）；
一旦跑过一次真实流水线，界面自动切换到真实产物，不需要改配置。

## 与原型的关系

界面按 Stitch 原型（项目 `PRD Prototype UI Design`）复刻，并按 PRD 的功能模块
做了取舍：

- 原型的右侧「可复核性」栏改为可点击的**证据抽屉**，避免每页重复一列；
- 六张分析图改为**手写 SVG**，因此没装 matplotlib 也能在界面上看到图，
  且鼠标可读数、可切换数值视图（不依赖颜色）；
- 原型没有的「历史运行」「设置」两页按 PRD 补上；
- 全站统一 `【事实】/【推论】/【观点】/AI 生成/代码判断` 五种内容性质标注。

## 已验证

- 12 个页面在真实产物与演示数据两种模式下均无渲染错误。
- 真实流水线端到端跑通后，界面自动切换为真实数据（本次验证运行编号
  `20261003T213300583`），产物清单、哈希、轨迹、校验结论全部来自产物文件。
- 缺 `matplotlib` 时页面顶部给出降级横幅，图表区用 SVG 替代，其余内容不受影响。
