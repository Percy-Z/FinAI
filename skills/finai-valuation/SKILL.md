# 自动化估值建模

这个技能把估值从「打开 Excel 手算」变成「跑一条可复现的流水线」。

## 什么时候用

- 用户给了一家公司，要一个估值区间或内在价值
- 用户要 DCF、可比公司估值、敏感性分析、反向估值
- 用户问「这个价格贵不贵」「市场隐含了什么假设」
- 用户要一份能交出去的估值报告

**不要**在没有财务数据的情况下硬跑：这个技能需要真实的财务输入，
而不是让模型自己编数字。

## 先确认输入齐不齐

跑之前检查四个文件（都在 `data/` 下）：

| 文件 | 内容 | 缺了会怎样 |
| --- | --- | --- |
| `assumptions.toml` | 经营假设、WACC 参数、终值假设、基期资产负债表、假设依据台账 | 直接跑不了 |
| `market.csv` | 目标公司与可比公司的股价、股数、债务（基准日快照） | 估值桥算不出来 |
| `peers.csv` | 可比公司的年度财务数据 | 相对估值会跳过全部倍数 |
| `apikey.txt` | 大模型接口的 key（也可以放环境变量 `DEEPSEEK_API_KEY`） | 报告没有推理与结论，只剩数据表 |

其中 `[opening_balance]` 与 `peers.csv` 目前是手填的过渡数据，
将来应由年报抽取生成（见「用年报核对基期数据」一节）。

## 跑一遍

```bash
cd <仓库根目录>
make verify          # 测试 + 配置 + 跑一遍 + 验收产物
# 或只跑：
make run
```

产物在 `runs/<运行编号>/`：十个数据文件（01-10）、六张图（11-16）、
报告（17 的 Markdown 与 18 的自包含 HTML）。编号固定，报告里按编号引用。

耗时约 3 分钟，其中 2 分半是大模型写报告。

## 看结果时要检查什么

1. **第一节「投资结论」是不是真的结论** —— 应该给出方向性判断和失效条件，
   而不是「仅供参考」。
2. **第四节「假设合理性审查」** —— 应该点名哪条假设最可能出错、需要什么证据。
   如果它只是把假设复述一遍，说明提示词或事实表出了问题。
3. **附录 10.3 的数字校验** —— 报告里的数字有没有事实表之外的。
   有的话逐个核查，那是模型编的。
4. **报告开头有没有红色横幅** —— 有横幅说明这份报告不合格（缺大模型或缺图）。

## 用年报核对基期数据

`[opening_balance]` 现在是手填的，属于「历史事实」，正确来源是年报。
用 `extract_annual_report` 工具（或命令行）从年报 PDF 里抽：

```bash
python3 -m algorithm.finai.extract <年报.pdf>
```

它会输出每个科目的数值、页码与原文片段，方便逐条核对。
扫描件（没有文字层）会被明确标出来 —— 那种文件要先做 OCR。

## 可用的工具（MCP）

通过 `mcp_server` 暴露，任何支持 MCP 的客户端都能调用：

- `run_valuation_pipeline` —— 跑完整流水线
- `get_valuation` —— 读某次运行的估值结果
- `list_runs` —— 列出最近几次运行及产物完整性
- `check_run` —— 验收某次运行的产物
- `extract_annual_report` —— 从年报 PDF 抽关键科目

## 结果出问题时怎么排查

| 现象 | 先看哪里 |
| --- | --- |
| 报告开头有「不含大模型」横幅 | `apikey.txt` 或环境变量；再跑 `make run` 看终端提示 |
| 报告开头有「不含图表」横幅 | 当前 python 有没有 matplotlib：`python3 -c "import matplotlib"` |
| 相对估值倍数全是空的 | `data/peers.csv` 里是不是缺这家公司 |
| 勾稽校验有失败项 | `02_validation_report.json` 里失败项的 `difference` 与 `evidence` |
| 数字校验列出可疑数字 | 逐个核对；那是模型写的、事实表里没有的数 |
| 流水线报「基期资产负债表不平」 | `[opening_balance]` 的资产 = 负债 + 权益 |

**不要**为了让流水线跑通而删掉检查或放宽约束 —— 那会把问题藏到报告里。
报错信息都写明了是哪个文件的哪个字段。

## 底线

- 数字全部由代码算，模型只负责解释与判断。**不要让模型算数。**
- 假设没有依据就写「待查」，不要编一个看起来合理的数。
- 报告里缺数据、有告警、有失败项，都要如实呈现，不许抹平。
